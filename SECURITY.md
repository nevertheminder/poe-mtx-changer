# Security

Please do not post security problems in an issue. Contact the maintainer privately on GitHub instead (or use
**Security → Report a vulnerability** if the repository offers it). Include the app version and how to reproduce it.

Examples of what counts: the app writing outside the game, backup or settings folders; a profile or settings file that
makes the app run code or overwrite files without asking; a restore that leaves the game broken.

The app loads Oodle and FMOD libraries that you choose or that it finds on your PC. Only use libraries from sources
you trust.

Only the latest release gets fixes.
